Cómo conseguir la credencial

Cesium ion, gratis para uso personal y sin tarjeta:

  1. Crea una cuenta en ion.cesium.com.
  2. En Access Tokens, copia el token por defecto.
  3. Pégalo en el campo de credencial.

Google Maps Platform, con cuenta de facturación: habilita la Map Tiles API y crea una clave sin restricción de sitio web, porque el juego se abre como archivo local.
